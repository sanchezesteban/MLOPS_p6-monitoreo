# Metadatos fuente de recaptura v2

Copias byte por byte de los dos CSV originales, antes de seleccionar o normalizar:
58 filas principales (cuatro JPEG eliminados manualmente, preservados en ZIP privado)
y seis adicionales fuera de riesgo. Sus rutas son las originales de cada fuente,
no rutas al dataset definitivo. Los frame_id se repiten entre fuentes; unir por
fuente + sesión + ID + SHA. No concatenar sin la correspondencia documentada.
No contiene consentimiento, predicciones ni nuevas anotaciones.

La selección definitiva usa 48 principales + seis adicionales + 24 S1/S5 anteriores.
Ver ../../../docs/seleccion_78_p5_05b.md y ../../../docs/normalizacion_temporal_S2_p5_05b.md.
Los JPEG fuente/ZIP y respaldos completos permanecen privados y no se borraron.
No usar este archivo histórico como entrada de evaluación o ajuste.
